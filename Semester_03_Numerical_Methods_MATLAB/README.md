# Semester 3 — Numerical Methods & Scientific Computing (MATLAB)

Scientific computation and numerical analysis coursework using MATLAB and Simulink. Covers linear algebra, non-linear root finding (Bisection, Newton-Raphson, Secant), ODE numerical solutions (Euler method), numerical integration (Trapezoidal, Simpson 1/3 and 3/8), 2D/3D data visualization, and traffic density modeling.

### How to Run
- **MATLAB CLI / Desktop:** Open MATLAB and execute the `.m` scripts directly.
- **GNU Octave Compatibility:** Most standard numerical scripts can also be run using GNU Octave:
```bash
octave --no-gui exp06_bisection_root_finding/exp06_bisection_polynomial_quadratic.m
```
- **Simulink Models (`.slx`):** Open directly inside MATLAB Simulink environment.
