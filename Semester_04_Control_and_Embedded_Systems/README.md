### How to Run & Simulate
- **8051 Assembly (`.asm`):** Assemble and simulate using Keil uVision (C51/A51), MCU 8051 IDE, or Proteus VSM.
- **Linear Control Systems (`.m`, `.slx`):** Run in MATLAB with the Control System Toolbox and Simulink.
